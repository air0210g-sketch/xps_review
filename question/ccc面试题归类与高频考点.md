## 四、备考建议（按投入产出）

1. **必须先打通的主线**：**项目（STAR + 数据）** → **MySQL（索引 + 事务/MVCC + 锁）** → **Redis（持久化 + 缓存三问题 + 分布式锁）** → **Kafka（可靠 + 顺序/幂等 + 堆积）** → **Go（GMP + Map + Channel + GC）**。  
2. **算法**：保持「数组/链表/哈希/二叉树/滑动窗口」高频题手感；文档中 **LRU、链表、数组第 K 大** 重复度高，可优先刷。  
3. **网络**：**TCP 状态机 + DNS/URL 全流程** 出现面极广，适合打包成一页纸反复背。  
4. **开放题**：秒杀、对账、ID 发号、关注系统等可准备 **1 分钟架构草图 + 核心风险点**，不必求全。
